# travel-expense

出張・学会参加の**請求内訳書**（交通費・宿泊費・参加費など）をブラウザで作って PDF にするツールです。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge）で開く
2. 左のフォームに入力すると、右に A4 のプレビューがリアルタイムで表示される
3. 「PDFを出力」→ 送信先で「PDFに保存」

インストール・サーバーは不要です。入力内容はブラウザ内にだけ保存され、外部には送信されません。

## 主な機能

- 地点（駅・停留所）を自動で登録し、次回からプルダウンで選択
- 区間ごとの路線・運賃を記憶して自動入力
- 経由地、帰りの区間（⇄）、翌日への複製
- 宿泊日数の自動計算、各合計・総合計の自動計算
- JSON で保存・読込（別の PC に持ち運び可能）

要件の詳細は [REQUIREMENTS.md](REQUIREMENTS.md) を参照してください。
